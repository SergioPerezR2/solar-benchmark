# solar-benchmark

Comparative benchmark of metaheuristic hyperparameter optimization (**GA**, **PSO**, **ABC**, **TPE**) for deep learning models (**MLP**, **LSTM**, **GRU**) applied to global solar irradiance (GHI) forecasting. Code and experiments supporting the article *"Comparative Benchmark of Metaheuristic Hyperparameter Optimization for Deep Learning Models in Global Solar Irradiance Forecasting"* (submitted to *Energies*, MDPI).

## Study area and data

- **Dataset:** PVGIS-ERA5 reanalysis data for Querétaro, México (lat 20.563425, lon -100.36943889), plus a local automated weather station reference (`data/EMA--OMUAQ_Table1.txt`).
- PVGIS data is not stored in the repo; it is downloaded on demand with `data/download_pvgis.py`.

## Repository structure

```
data/                   Raw/reference data and the PVGIS download script
notebooks/
  01_preprocessing.ipynb            Cleaning/scaling of the station time series
  01b_pvgis_preprocessing.ipynb     Preprocessing of the PVGIS-ERA5 dataset
  02_models.ipynb                   Baseline models (MLP, CNN1D, LSTM, GRU) on station data
  02b_models_pvgis.ipynb            Baseline models (MLP, LSTM, GRU) on PVGIS data, seeds 0-4
  03_optimization.ipynb             Metaheuristic hyperparameter optimization (dev/exploration)
  03_benchmark.ipynb                Main experiment: GA vs PSO vs ABC vs TPE, 3 models x 30 seeds
  03_benchmark_output.ipynb         Executed copy of 03_benchmark.ipynb (reference output)
  03b_feature_selection_optimization.ipynb   Joint LSTM hyperparameter + feature selection search
  04_analysis.ipynb                 Statistical analysis and figures over the 360 benchmark runs
run_benchmark.sh        Headless execution of 03_benchmark.ipynb with progress notifications
requirements.txt        Python dependencies
```

`outputs/`, `mlruns/`, `models/`, and `datasets/` are generated by the notebooks and are not versioned (see `.gitignore`); they are recreated by running the pipeline below.

## Reproducing the results

1. **Environment**
   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. **Data**
   ```bash
   python data/download_pvgis.py
   ```
3. **Pipeline** (run notebooks in order with Jupyter, or headless with `jupyter nbconvert --execute`)
   - `01_preprocessing.ipynb` / `01b_pvgis_preprocessing.ipynb`
   - `02_models.ipynb` / `02b_models_pvgis.ipynb`
   - `03_benchmark.ipynb` — the main article experiment (GA/PSO/ABC/TPE x MLP/LSTM/GRU x 30 seeds). Can also be launched headlessly:
     ```bash
     ./run_benchmark.sh
     ```
   - `03b_feature_selection_optimization.ipynb` — supplementary joint feature-selection/HPO study
   - `04_analysis.ipynb` — reproduces the statistical tests and figures from the article
4. **Experiment tracking:** all runs are logged with [MLflow](https://mlflow.org/) under `mlruns/`. Inspect them with:
   ```bash
   mlflow ui
   ```
